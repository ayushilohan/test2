About this tool

This is a lightweight client-side tool to help deploy Tizen (.wgt) packages to Samsung TVs. It attempts to discover TVs on your local network and call common Tizen installation endpoints. Due to browser CORS and TV settings, some requests may be blocked — run a proxy or use a local server if needed.
